## 中文

使用 **Python** 和 **HTML/JavaScript** 实现的精美爱心动画。

### 功能特点
- 基于数学曲线绘制的动态爱心形状
- 粒子扩散效果（边缘和中心）
- 带有发光效果的光晕动画
- 两种实现：Python (tkinter) 和 HTML5 Canvas
- 易于运行，HTML 版本无需外部依赖

### 文件说明
| 文件 | 说明 |
|------|------|
| `heart.py` | Python 版本，使用 tkinter 实现 |
| `heart.html` | HTML5 Canvas 版本，浏览器直接运行 |

### 使用方法

**Python 版本：**
```bash
python heart.py
```

**HTML 版本：**
直接用浏览器打开 `heart.html` 文件即可。

### 效果预览
动画在黑色背景上展示一颗跳动的心形，带有粒子扩散效果。

## English

A beautiful heart animation implemented in both **Python** and **HTML/JavaScript**.

### Features
- Dynamic heart shape drawn with mathematical curves
- Particle diffusion effects (edge & center)
- Halo animation with glowing effects
- Two implementations: Python (tkinter) & HTML5 Canvas
- Easy to run, no external dependencies for HTML version

### Files
| File | Description |
|------|-------------|
| `heart.py` | Python implementation using tkinter |
| `heart.html` | HTML5 Canvas implementation, run in browser |

### Usage

**Python Version:**
```bash
python heart.py
```

**HTML Version:**
Simply open `heart.html` in your web browser.

### Preview
The animation displays a beating heart with particle effects on a black background.
